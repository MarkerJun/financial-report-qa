# 家电上市公司财报问答知识库

作业三，方向 A。十家 A 股家电相关公司，2025 年完整年报。数据来自巨潮资讯；下载地址、文件大小及 SHA256 见 data/manifest.json。

## 运行

Python 3.12，建议创建独立虚拟环境后安装依赖。

```powershell
python -m pip install -r requirements.txt
python download.py
python build.py
python -c "from engine import Engine; Engine()"
python evaluate.py
python app.py
```

打开 http://127.0.0.1:8033 。当前电脑已完成下载、抽取、索引，直接启动 app.py 即可。build.py 优先使用工作区已有的 .tmp_pdf_deps，其他机器会使用正常安装的 PyMuPDF。

## 模型配置

默认无需密钥：部分年度财务指标使用规则抽取数值和引用，解释题展示原文，未来问题拒答。要生成复杂自然语言答案，在启动程序的同一终端设置 LLM_API_KEY、LLM_BASE_URL、LLM_MODEL 环境变量，再启动 app.py。本项目不自动读取 .env；.env.example 仅说明变量名。不要提交真实密钥。

## 实现

- 按页抽取文字；带表格信号的页面使用 PyMuPDF 表格检测，按行列用竖线保存，完整表格不切碎。未识别出的表格仍可能成为布局文本，需要核验。
- 正文 1400 字符切块、200 字符重叠；包含公司、证券代码、年度、章节、PDF 页码及候选印刷页码。印刷页码和章节为启发式识别，引用以 PDF 页码为准。
- BM25 使用中文双字词、数字和英文分词，k1=1.5，b=0.75。
- 向量使用 TF-IDF + 192 维 TruncatedSVD（LSA），余弦相似度；这是统计语义向量，不是预训练 embedding 模型。无需下载模型、无需 GPU。
- 混合检索：两路各取前60块，RRF(k=60)合并，同公司同页去重，返回5页证据。
- 跨公司问题逐公司检索，避免只检索到少数公司后泛化整个行业。
- 生成模型接口可选；严格使用证据及 [E编号] 引用。尚未完成真实生成答案评价。

## 实测与限制

output/evaluation.json 保存10题×3种检索器的全部召回块。output/evaluation.md 为汇总。评测使用主要财务指标参考页命中情况，不代表答案正确率，也不是财报中所有有效证据的穷尽标注。不得把未配置模型的检索实验写成模型问答成功。

主要风险：跨页表头丢失、表格单位识别、财务指标口径、统计向量语义能力有限。当前10题中规则版8题通过参考值核对（含1题合理拒答），2题未回答；三种检索模式均为8/10，不能声称混合检索更优。九阳现金流量行被数值列打断，规则无法读取；收入口径解释也未回答。完整答案及失败原因见 output/evaluation.md。
